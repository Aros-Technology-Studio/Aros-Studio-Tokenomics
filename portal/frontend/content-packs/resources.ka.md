## Block: section
id: glossary
title: Key terms
* **AFC (Aros Financial Core)** — Aros API კონტრაქტის შესრულების პროცესი AST-სა და ლიცენზირებულ ანკერებს შორის. ის არ არის პლატფორმა, მეურვე ან იურიდიული პირი; ის მხოლოდ პროცესის მიმდინარეობისას არსებობს.
* **AST (Aros Studio Tokenomics)** — შესრულებისა და აღრიცხვის ძრავა: ცალკე იურიდიული პირი, რომელიც მხოლოდ საკუთარ სახსრებს ფლობს და ტოკენიზებულ უფლებებს აღრიცხავს.
* **API კონტრაქტი** — მანქანურად წაკითხვადი შეთანხმება, რომელიც განსაზღვრავს მხარეებს, მათ როლებს, შეტყობინებებს, პროცესის მდგომარეობებს, უკან დაბრუნებასა და აუდიტის მოვლენებს.
* **ლიცენზირებული ანკერი** — რეგულირებული ინსტიტუცია, რომელიც პროცესში ფულის ან ციფრული აქტივის ლიცენზირებულ გადაადგილებას საკუთარი ლიცენზიით ასრულებს.
* **ინიციატორი ინსტიტუცია** — ბანკი, ხაზინა ან სხვა ინსტიტუცია, რომელიც მოთხოვნას ავტორიზებას უკეთებს და მის შესვლამდე KYC, AML და სანქციების შემოწმებას ასრულებს. ის კონტრაქტის მხარე არ არის.
* **Proof of Transaction (PoT)** — ერთადერთი კარიბჭე, რომლითაც ღირებულება წარმოიქმნება ან იცვლება: ვერდიქტი იმისა, რომ პროცესმა ყველა საჭირო კრიტერიუმი დააკმაყოფილა.
* **NodeChain** — ყოველი მნიშვნელოვანი მდგომარეობის მხოლოდ დასამატებელი ჩანაწერი; ჭეშმარიტების ერთადერთი წყარო.
* **ArosCoin (ARO)** — AST-ის შიდა პროცესისა და გადახდის ერთეული. არ იყიდება, საბაზრო ფასი არ აქვს და ანგარიშსწორების აქტივი არ არის.
* **უფლებების ტოკენი** — ტოკენი, რომელიც რეალურ აქტივზე უფლებებს მისი ოფიციალური, დადასტურებული შეფასებით წარმოადგენს და მხოლოდ დადასტურებული პროცესებით იცვლება.
* **All-Seeing Eye** — დამოუკიდებელი მონიტორინგისა და აუდიტის ფენა: აკვირდება, აღრიცხავს და აცნობებს; ვეტოს უფლება არ აქვს და მოქმედება არ შეუძლია.
* **უკან დაბრუნება (rollback)** — გადახრილი პროცესის დაბრუნება მის ბოლო თანმიმდევრულ მდგომარეობაში, რაც თავადაც NodeChain-ზე აღირიცხება.
* **პროცესის ID** — პროცესის საჯარო მითითება; ნებისმიერს შეუძლია მკვლევარში მისი დაფარული სტატუსის ნახვა.

title: Is there a token I can buy?
- არა. Aros Studio ტოკენებს არ ყიდის. ArosCoin შიდა ერთეულია, რომელიც დადასტურებულ სამუშაოს ზომავს და ინფრასტრუქტურას უხდის; მას საბაზრო ფასი არ აქვს. უფლებების ტოკენები კონკრეტულ რეალურ აქტივებს წარმოადგენს და მხოლოდ ინსტიტუციებზე, დადასტურებული პროცესით გაიცემა.

title: Can I use AST or AFC as an individual?
- პირდაპირ — არა. ორივე ინსტიტუციებისთვისაა შექმნილი. ფიზიკური პირები სარგებელს იღებენ იმ ბანკების, ხაზინებისა და ლიცენზირებული კომპანიების მეშვეობით, რომლებიც მათ ინტეგრირებენ. პროცესის ნახვა საჯარო მკვლევარში ნებისმიერს შეუძლია.
