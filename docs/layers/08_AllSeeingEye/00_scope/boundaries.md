# Boundaries

| In | Out |
|----|-----|
| Observe / notify / history | Veto, rollback, mint |
| Subscribe to pipeline signals (orchestrator, etc.) | Becoming SoT or economic authority |
| Publish to durable observer stream (B4) | Client append rights on NodeChain |
| HTTP read of events / stream / health | HTTP executive actions |

Eye may consume NodeChain **events-out** / observer bus; it does not gain append or unverify powers via that channel.
