# Demo document package (D2)

Real PDF sample for **document-first** pilot e2e (not a legal instrument).

| File | Role |
|------|------|
| `valuation-sample.pdf` | Title + valuation annex text (generated) |
| Generated by | `npm run demo:pdf-package` or first run of `npm run demo:pdf-e2e` |

## Owner real file

```bash
# Use your own signed PDF:
npm run demo:pdf-e2e -- --pdf /path/to/your-signed.pdf --amount 500000 --currency USD
```

## Default demo (repo fixture)

```bash
# stack must be up: npm run home:up
npm run demo:pdf-e2e
```

See `docs/DEMO-PDF-E2E-D2.md`.
